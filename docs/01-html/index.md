# HTML 学习模块

系统化的 HTML 学习笔记：从文档骨架到语义化、表单、多媒体，再到 SEO 与可访问性，五章递进构建完整知识体系。

## 学习顺序

| 顺序 | 模块 | 内容 |
|:----:|------|------|
| 1 | [文档结构](/01-html/01-document-structure/) | 骨架模板、head 元数据、DOM 解析与加载阻塞 |
| 2 | [语义化标签](/01-html/02-semantic-tags/) | header/nav/main/article/section 等语义标签、文本/列表/表格 |
| 3 | [表单与验证](/01-html/03-forms-validation/) | 表单结构、input 类型、约束验证、提交机制 |
| 4 | [音视频与图片](/01-html/04-media-assets/) | 图片/视频/音频、Canvas、SVG、加载性能 |
| 5 | [SEO 与可访问性](/01-html/05-seo-a11y/) | 搜索引擎优化、ARIA、键盘导航、无障碍规范 |

> 每章统一采用「它是什么 → 核心机制 → 标准语法 → 深入理解 → 关联速查」五段式结构，并配套独立速查卡片（`cheatsheet/html/`）。

## 学完你将能

- 写出标准、无阻塞的 HTML 文档骨架（理解 DOM 解析与加载原理）
- 用语义化标签组织页面结构，服务 SEO 与辅助技术
- 制作含完整验证机制的表单
- 合理使用图片/音视频/Canvas，并优化媒体加载性能
- 掌握 SEO 基础与可访问性规范，让页面"机器可懂、人人可用"
