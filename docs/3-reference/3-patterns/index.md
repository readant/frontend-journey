# 📦 代码骨架

> **定位**：手册的「成品仓库」—— 复制即用的完整代码片段，解决「会查原理、不会组装」的问题。
>
> 手册讲原理，场景索引给方案，这里直接给**能跑的最小成品**。

## 说明

每个骨架 = 完整可运行的最小片段（HTML/CSS/JS 或纯片段），配套「改哪里、为什么这么写」的标注。内容按领域组织，与 [📖 知识手册](/3-reference/1-handbook/) 章节一一对应。
