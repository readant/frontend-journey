# 📚 参考层 · 手边书

> **定位**：三层架构的第三层 —— 完整的知识储备 + 快速检索入口。
>
> 学习层回答「为什么」，实战层回答「怎么做」，**参考层回答「忘了去哪查」**。

## 设计逻辑

参考层的核心是**完整知识手册**，场景索引与星盘都建立在手册之上：

```
📖 知识手册（内容本体）  →  🔍 场景索引（快速入口）  →  🕊️ 知识星盘（可视化导航）
```

**手册是本体，索引是入口。没有手册，索引就是空壳。**

## 结构导航

| 模块 | 内容 | 解决什么问题 |
| :--- | :--- | :--- |
| [🕊️ 知识星盘](/3-reference/) | 把知识体系画成夜空，点星导航 | 忘记知识点放在哪 |
| [📖 知识手册](/3-reference/1-handbook/css/) | 按技术域系统整理的全部知识点 | 想系统学透、查完整原理 |
| [🔍 场景索引](/3-reference/2-scenarios/layout) | 按中文意图反查方案（摘要 + 链接） | 记得「我要做什么」，忘了「怎么做」 |
| [📦 代码骨架](/3-reference/) | 复制即用的完整片段（建设中） | 会查不会写，需要可直接粘贴的模板 |

## 使用建议

- **忘记在哪查**：进 [🕊️ 知识星盘](/3-reference/)，点一颗星 → 跳到对应手册章节
- **想系统学习**：按 [📖 知识手册](/3-reference/1-handbook/css/) 章节顺序通读
- **开发时快速定位**：按中文意图查 [🔍 场景索引](/3-reference/2-scenarios/layout)，需要完整原理再回手册
- **写代码要模板**：进 [📦 代码骨架](/3-reference/3-patterns/) 直接复制
