# 工程化手册

## 概述

工程化解决「一个人写页面没问题，一个团队维护大型项目就崩溃」的问题：**版本控制管历史、包管理器管依赖、构建工具管打包**。本手册按工具域系统整理，是「忘了命令/配置怎么用就来查」的完整储备。
