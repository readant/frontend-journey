# JS 闭包 · 术语速查表

> **定位**：闭包域全部术语的**四要素速查**——定义 / 语法示例 / 使用场景 / 注意事项。系统学习请先走学习层
> [作用域与词法环境](/03-js/02-functions/05-scope) → [闭包](/03-js/02-functions/06-closure)。

## 一、核心概念

### 闭包（Closure）

| 要素     | 内容                                                                                                      |
| :------- | :-------------------------------------------------------------------------------------------------------- |
| 定义     | **内层函数 + 它出生时的词法环境**的组合。外层函数执行完后，被内层函数捕获的变量依然存活（类比"记忆背包"） |
| 语法示例 | `function makeCounter() { let n = 0; return () => ++n; }` → `makeCounter()` 返回的函数仍能读 `n`          |
| 使用场景 | 计数器、私有变量、防抖/节流、记忆化、模块封装、React Hooks                                                |
| 注意事项 | 闭包捕获的是**变量本身**（不是当时的快照）；每次调用外层函数生成**独立**闭包                              |

### 词法作用域（Lexical Scope）

| 要素     | 内容                                               |
| :------- | :------------------------------------------------- |
| 定义     | 变量可见性由**书写（定义）位置**决定，而非调用位置 |
| 语法示例 | 函数写在哪层，就能访问哪层及以上的外层变量         |
| 使用场景 | 预测变量查找路径；理解闭包"记住环境"的根源         |
| 注意事项 | 与动态作用域（运行时决定）相反——JS 是词法作用域    |

### 环境记录 / 外部引用（Environment Record / outer）

| 要素     | 内容                                                                      |
| :------- | :------------------------------------------------------------------------ |
| 定义     | 词法环境 = 环境记录（本层变量表）+ 外部环境引用（指向外层，串成作用域链） |
| 语法示例 | `inner` 环境记录里有 `b`，outer 指向 `outer` 函数的环境                   |
| 使用场景 | 画内存图、解释闭包为何"抓住"外层变量                                      |
| 注意事项 | 全局环境的 outer 是 `null`（查找终点）                                    |

## 二、经典应用模式

### 私有变量（Private Variable）

| 要素     | 内容                                                                                                                       |
| :------- | :------------------------------------------------------------------------------------------------------------------------- |
| 定义     | 用闭包把变量"关"在函数内部，外部只能通过暴露的方法操作                                                                     |
| 语法示例 | `function createAccount(init) { let balance = init; return { deposit(n) { balance += n; }, get() { return balance; } }; }` |
| 使用场景 | 银行账户、购物车、任何"状态不能被外部乱改"的场景                                                                           |
| 注意事项 | 外部直接访问 `account.balance` 得到 `undefined`（拿不到）                                                                  |

### 计数器（Counter）

| 要素     | 内容                                                                     |
| :------- | :----------------------------------------------------------------------- |
| 定义     | 利用闭包让计数变量跨多次调用存活                                         |
| 语法示例 | `const c = (() => { let n = 0; return () => ++n; })(); c(); c();` → 1, 2 |
| 使用场景 | 生成唯一 id、统计点击次数                                                |
| 注意事项 | 每次 `createCounter()` 都是独立的计数器，互不干扰                        |

### 函数工厂 / 柯里化（Function Factory / Currying）

| 要素     | 内容                                                                             |
| :------- | :------------------------------------------------------------------------------- |
| 定义     | 外层函数"记住"一部分参数，返回的函数继续接收剩余参数                             |
| 语法示例 | `const add = (a) => (b) => a + b; add(1)(2);` · `const add5 = add(5); add5(10);` |
| 使用场景 | 预填配置、复用固定参数的逻辑                                                     |
| 注意事项 | 写法是两层箭头 `a => b => ...`；调用是两个括号 `add(1)(2)`                       |

### 防抖（Debounce）

| 要素     | 内容                                                                                                                                |
| :------- | :---------------------------------------------------------------------------------------------------------------------------------- |
| 定义     | 连续触发时**重置计时**，只有停下来超过 delay 才执行最后一次                                                                         |
| 语法示例 | `function debounce(fn, delay = 300) { let t; return (...args) => { clearTimeout(t); t = setTimeout(() => fn(...args), delay); }; }` |
| 使用场景 | 搜索框输入、窗口 resize、按钮防连点                                                                                                 |
| 注意事项 | 计时器 `t` 必须由闭包保存；忘记 `clearTimeout` 会退化成"延迟执行多次"                                                               |

### 节流（Throttle）

| 要素     | 内容                                                                                                                                                          |
| :------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 定义     | 固定时间间隔内**最多执行一次**                                                                                                                                |
| 语法示例 | `function throttle(fn, delay = 300) { let last = 0; return (...args) => { const now = Date.now(); if (now - last >= delay) { last = now; fn(...args); } }; }` |
| 使用场景 | 滚动监听、拖拽、游戏高频事件                                                                                                                                  |
| 注意事项 | 防抖"只执行最后一次"，节流"按频率执行"——别混用                                                                                                                |

### 记忆化（Memoize）

| 要素     | 内容                                                                                                                                 |
| :------- | :----------------------------------------------------------------------------------------------------------------------------------- |
| 定义     | 用参数作 key 缓存函数结果，重复调用直接返回缓存                                                                                      |
| 语法示例 | `function memoize(fn) { const cache = new Map(); return (k) => cache.has(k) ? cache.get(k) : (cache.set(k, fn(k)), cache.get(k)); }` |
| 使用场景 | 昂贵计算（递归、大数据处理）的加速                                                                                                   |
| 注意事项 | key 用对象时要小心（对象转字符串都是 `"[object Object]"`），用 Map + 对象引用或字符串化 key                                          |

### 模块模式（Module Pattern）

| 要素     | 内容                                                                                                                |
| :------- | :------------------------------------------------------------------------------------------------------------------ |
| 定义     | IIFE 立即执行，内部变量私有，返回对象暴露公共接口                                                                   |
| 语法示例 | `const store = (function () { let data = []; return { add(x) { data.push(x); }, getAll() { return data; } }; })();` |
| 使用场景 | 旧时代"命名空间 + 私有状态"（现多用 ES Module）                                                                     |
| 注意事项 | IIFE 前一行忘写分号会被"吃掉"报错                                                                                   |

## 三、陷阱与内存

### var 循环陷阱（Loop Trap）

| 要素     | 内容                                                                               |
| :------- | :--------------------------------------------------------------------------------- |
| 定义     | `for (var i...)` 中 var 无块级作用域，所有闭包共享同一个 `i`，循环结束输出统一终值 |
| 语法示例 | `for (var i = 0; i < 3; i++) setTimeout(() => console.log(i));` → `3 3 3`          |
| 使用场景 | 循环里创建事件回调 / 定时器时必查                                                  |
| 注意事项 | 修复 ① 用 `let`（每次迭代独立作用域）② 旧代码用 IIFE 立即捕获 `((n) => ...)(i)`    |

### 内存泄漏（Memory Leak）

| 要素     | 内容                                                              |
| :------- | :---------------------------------------------------------------- |
| 定义     | 闭包长期持有外层环境引用，使本该回收的变量堆积在堆上              |
| 语法示例 | `let f = makeCounter();` 长期全局引用，闭包环境永不释放           |
| 使用场景 | 长生命周期页面（SPA）中反复创建闭包时                             |
| 注意事项 | 用完置空引用（`f = null`）、解除事件监听（`removeEventListener`） |
