# JS 运算符

## 核心概念

运算符 = 对值做「算、比、判、赋」的动作 —— 算术算数、比较分大小、逻辑做决策。

## 完整内容

### 是什么 / 为什么

表达式由「操作数 + 运算符」构成。掌握运算符的行为与优先级，才能写对条件和计算。最常踩坑的是 `+` 的拼接陷阱、`==` 的隐式转换、逻辑运算符的短路返回值。

### 一、算术运算符

```javascript
5 + 3;   // 8（数字相加）
5 - 3;   // 2
5 * 3;   // 15
5 / 2;   // 2.5（不是整除！）
5 % 2;   // 1（取余，判断奇偶用）
2 ** 3;  // 8（幂运算）
++i / i++;  // 先加后取 / 先取后加（少用后缀，易乱）
```

**陷阱**：`+` 遇到字符串变拼接。

```javascript
1 + 2 + "3";    // "33"（先 1+2=3，再 3+"3" 拼接）
"1" + 2 + 3;    // "123"（一路拼接）
```

### 二、比较运算符

```javascript
5 > 3;    // true
5 >= 5;   // true
"a" < "b";  // true（字符串按字典序比较）

// 相等三兄弟
5 == "5";     // true  （== 隐式转换，避免使用）
5 === "5";    // false （=== 类型也要一致，推荐）
NaN === NaN;  // false （NaN 不等于任何值，用 Number.isNaN() 判断）
```

### 三、逻辑运算符（短路求值）

```javascript
true && false;   // false
true || false;   // true
!true;           // false

// 短路：&& 遇假即停返回该值，|| 遇真即停返回该值
"" || "默认值";      // "默认值"（取默认值常用）
"有值" && "继续";     // "继续"（有值才执行后段）
user && user.name;  // 防空指针经典写法
```

**返回值是「操作数本身」**，不一定是 true/false：

```javascript
const name = input || "匿名";   // input 为空就用默认
const flag = a > 0 && b > 0;    // 需要布尔结果时包一层 Boolean()
```

### 四、赋值与空值合并

```javascript
let n = 10;
n += 5;    // n = 15（+= -= *= /= %= **=）
n ??= 0;   // 逻辑空赋值：n 为 null/undefined 才赋 0
n ||= 1;   // n 为假值才赋 1（0/"" 也会被覆盖，慎用）
```

**?? vs || 的区别**：

```javascript
0 || 10;      // 10（0 是假值被覆盖）
0 ?? 10;      // 0（?? 只看 null/undefined）
"" || "x";    // "x"
"" ?? "x";    // ""（空串保留）
```

### 五、三元与可选链

```javascript
// 三元：条件 ? 真 : 假
const type = age >= 18 ? "成年" : "未成年";

// 可选链：防中间层为空
const city = user?.address?.city;   // 任一为空返回 undefined，不抛错
const len = arr?.[0];               // 数组可选索引
```

### 语法速查（优先级从高到低）

| 类别 | 运算符 | 说明 |
| :--- | :--- | :--- |
| 一元 | `!` `+` `-` `typeof` `++` `--` | 单操作数 |
| 幂 | `**` | 幂运算 |
| 乘除 | `*` `/` `%` | 乘法族 |
| 加减 | `+` `-` | 加法族（注意拼接） |
| 比较 | `<` `>` `<=` `>=` | 大小比较 |
| 相等 | `===` `!==` `==` `!=` | 用全等 |
| 逻辑与 | `&&` | 短路 |
| 逻辑或 | `\|\|` | 短路 |
| 空值 | `??` | 仅 null/undefined 兜底 |
| 三元 | `? :` | 三目 |
| 赋值 | `=` `+=` 等 | 最右，右结合 |

### 常见用法

**默认参数（两个版本）**：

```javascript
// 参数默认值（推荐）
function greet(name = "匿名") { return `你好，${name}`; }

// 空值兜底
const price = data?.price ?? 0;
```

**守卫式执行**：

```javascript
if (isLogin && fetchUser()) {}   // 前置条件不满足就短路，不执行后段
```

### 注意事项

- ⚠️ 判断相等只用 `===`，`==` 的隐式转换是万恶之源。
- ⚠️ `&&`/`||`/`??` 返回的是**操作数本身**，需要布尔值时记得 `!!x` 或 `Boolean(x)`。
- ⚠️ 别混用 `||` 和 `??`：`0 || x` 会丢 0，数据可能为 0 的场景用 `??`。
- ⚠️ `%` 是取余不是模，负数结果与取模不同（`-5 % 2 === -1`）。
- ⚠️ 浮点运算有精度误差，判断相等用 `Math.abs(a - b) < 1e-9`。
