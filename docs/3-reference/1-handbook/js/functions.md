# JS 函数 · 术语速查表

> **定位**：函数域全部术语的**四要素速查**——定义 / 语法示例 / 使用场景 / 注意事项。忘记某个概念随时来查；系统学习请走学习层
> [函数与闭包章节](/03-js/02-functions/)。

## 一、函数基础概念

### 函数（Function）

| 要素     | 内容                                                                       |
| :------- | :------------------------------------------------------------------------- |
| 定义     | 把一段「输入 → 计算 → 输出」的流程打包成可重复调用的单元（类比自动售货机） |
| 语法示例 | `function add(a, b) { return a + b; }`                                     |
| 使用场景 | 任何需要重复执行的逻辑：计算、校验、格式化、事件处理                       |
| 注意事项 | JS 中函数是**一等公民**：可赋值、可传参、可返回                            |

### 一等公民（First-Class Citizen）

| 要素     | 内容                                                                                       |
| :------- | :----------------------------------------------------------------------------------------- |
| 定义     | 函数可以像数字/字符串一样被当作"值"使用                                                    |
| 语法示例 | `const fn = function () {};` · `arr.map(x => x * 2)` · `function f() { return () => {}; }` |
| 使用场景 | 回调函数、高阶函数、闭包的地基                                                             |
| 注意事项 | 这是 JS 区别于"函数只能调用"的语言（如老式 C）的核心特性                                   |

## 二、定义方式

### 函数声明（Function Declaration）

| 要素     | 内容                                                             |
| :------- | :--------------------------------------------------------------- |
| 定义     | 以 `function` 关键字开头定义具名函数                             |
| 语法示例 | `function add(a, b) { return a + b; }`                           |
| 使用场景 | 模块内顶层通用函数；依赖提升的场景（很少）                       |
| 注意事项 | **有提升**：函数体整体就绪，可先调用后定义。声明末尾**不加分号** |

### 函数表达式（Function Expression）

| 要素     | 内容                                                           |
| :------- | :------------------------------------------------------------- |
| 定义     | 把函数作为值赋给变量，可匿名                                   |
| 语法示例 | `const sub = function (a, b) { return a - b; };`               |
| 使用场景 | 需要把函数当值存/传时；条件分支里选不同函数                    |
| 注意事项 | **无提升**：赋值前调用报 `TypeError`。表达式语句末尾**加分号** |

### 箭头函数（Arrow Function）

| 要素     | 内容                                                                                                  |
| :------- | :---------------------------------------------------------------------------------------------------- |
| 定义     | `=>` 连接参数与函数体的简写语法；单表达式自动返回                                                     |
| 语法示例 | `const mul = (a, b) => a * b;` · `const dbl = x => x * 2;` · `() => ({ ok: true })`                   |
| 使用场景 | 短小回调、遍历逻辑、需要继承外层 this 的场景                                                          |
| 注意事项 | **没有自己的 this/arguments、不能 new**；返回对象要加括号 `() => ({...})`；多语句必须 `{}` + `return` |

### 立即执行函数（IIFE）

| 要素     | 内容                                                   |
| :------- | :----------------------------------------------------- |
| 定义     | 定义完立刻执行一次的匿名函数，`(函数体)(参数)`         |
| 语法示例 | `(function () { const secret = 1; })();`               |
| 使用场景 | 旧时代创建独立作用域、避免污染全局（现多用 ES Module） |
| 注意事项 | 前面一行忘写分号会被"吃掉"报错                         |

## 三、参数

### 形参 / 实参（Parameter / Argument）

| 要素     | 内容                                                                          |
| :------- | :---------------------------------------------------------------------------- |
| 定义     | 形参 = 定义时的"接收口"变量名；实参 = 调用时实际传入的值                      |
| 语法示例 | `function greet(name) {...}`（name 是形参）→ `greet("小明")`（"小明" 是实参） |
| 使用场景 | 一切函数传值                                                                  |
| 注意事项 | 少传 → 实参为 `undefined`；多传 → 多余参数被忽略                              |

### 默认参数（Default Parameter）

| 要素     | 内容                                                                   |
| :------- | :--------------------------------------------------------------------- |
| 定义     | 形参后写 `= 默认值`，调用者不传（或传 undefined）时使用                |
| 语法示例 | `function greet(name = "访客") { return "你好，" + name; }`            |
| 使用场景 | 可选参数、配置项兜底                                                   |
| 注意事项 | **只有 `undefined` 触发默认值**（`null` 不会）；默认值可使用前面的参数 |

### rest 参数（Rest Parameter）

| 要素     | 内容                                                                |
| :------- | :------------------------------------------------------------------ |
| 定义     | `...rest` 写在最后一个形参，收集多余参数为**真数组**                |
| 语法示例 | `function sum(...nums) { return nums.reduce((a, b) => a + b, 0); }` |
| 使用场景 | 数量不定的参数（求和、日志、事件转发）                              |
| 注意事项 | 必须放参数列表**最后**；比 `arguments` 更好用（真数组）             |

### arguments（类数组对象）

| 要素     | 内容                                                                             |
| :------- | :------------------------------------------------------------------------------- |
| 定义     | 旧式：函数内部可用 `arguments` 拿到所有实参（类数组，非真数组）                  |
| 语法示例 | `function log() { console.log(arguments.length); }`                              |
| 使用场景 | 老代码维护（新代码用 rest 参数替代）                                             |
| 注意事项 | **箭头函数没有 arguments**；类数组没有 `map` / `filter`，需展开 `[...arguments]` |

### 解构参数（Destructured Parameter）

| 要素     | 内容                                                         |
| :------- | :----------------------------------------------------------- |
| 定义     | 形参直接解构对象/数组，取其中的字段                          |
| 语法示例 | `function show({ id, title }) { console.log(id, title); }`   |
| 使用场景 | 传配置对象、处理 API 返回数据                                |
| 注意事项 | 可为解构字段设默认值 `({ id = 0 } = {})` 防 `undefined` 报错 |

## 四、返回值

### return

| 要素     | 内容                                                                       |
| :------- | :------------------------------------------------------------------------- |
| 定义     | 把函数体计算结果交给调用者，并**立即结束函数**                             |
| 语法示例 | `return a + b;` · `return;`（返回 undefined）                              |
| 使用场景 | 一切需要"输出结果"的函数                                                   |
| 注意事项 | return 后代码不执行；**return 换行**会被 ASI 拆成 `return;` 返回 undefined |

### undefined 返回值

| 要素     | 内容                                                                  |
| :------- | :-------------------------------------------------------------------- |
| 定义     | 没写 return / return 没带值 / return undefined 时，函数返回 undefined |
| 语法示例 | `function noop() {}` → `noop()` 是 `undefined`                        |
| 使用场景 | 只做副作用（打印、修改外部状态）的函数                                |
| 注意事项 | 与 `null` 是两回事；`console.log` 是打印，不是返回                    |

### 多值返回（对象 / 数组打包）

| 要素     | 内容                                                      |
| :------- | :-------------------------------------------------------- |
| 定义     | 函数只能返回一个值；多个结果用对象/数组打包，外部解构接收 |
| 语法示例 | `return { min, max };` → `const { min, max } = f();`      |
| 使用场景 | 同时返回多个计算结果（坐标、统计、分页）                  |
| 注意事项 | 别写 `return a, b`（逗号表达式只返回 b）                  |

## 五、this 绑定

### this

| 要素     | 内容                                                                           |
| :------- | :----------------------------------------------------------------------------- |
| 定义     | 函数内部关键字，指向"当前执行上下文的主人"，**由调用方式决定**（类比话筒）     |
| 语法示例 | `obj.fn()` → this = obj · `fn()` → this = 全局/undefined · `new Fn()` → 新对象 |
| 使用场景 | 对象方法、构造函数、事件回调                                                   |
| 注意事项 | 判断顺序：点调用 → new → call/apply/bind → 裸调用                              |

### call / apply / bind

| 要素     | 内容                                                                           |
| :------- | :----------------------------------------------------------------------------- |
| 定义     | 手动指定 this 的三种方法：call/apply 立即调用，bind 返回永久锁定 this 的新函数 |
| 语法示例 | `f.call(obj, a, b)` · `f.apply(obj, [a, b])` · `const g = f.bind(obj)`         |
| 使用场景 | 借用方法、固定回调的 this、偏函数（bind 预填参数）                             |
| 注意事项 | call 逐个传参、apply 数组传参；bind 不立即执行                                 |

### 箭头函数的 this（词法绑定）

| 要素     | 内容                                                                      |
| :------- | :------------------------------------------------------------------------ |
| 定义     | 箭头函数没有自己的 this，读取**定义时外层作用域**的 this，永不改变        |
| 语法示例 | `setTimeout(() => console.log(this.name), 0)` 继承外层 this               |
| 使用场景 | 回调嵌套、定时器、Promise 链中"借用外层 this"                             |
| 注意事项 | 对象方法 / DOM 事件回调 / 构造函数**不要用**箭头函数（this 取不到调用者） |

## 六、作用域（闭包前置）

### 作用域（Scope）

| 要素     | 内容                                                                               |
| :------- | :--------------------------------------------------------------------------------- |
| 定义     | 变量"可见的范围"：全局 / 函数 / 块级（类比楼层：内层能访问外层）                   |
| 语法示例 | `let g = 1;`（全局）· 函数内 `let x`（函数作用域）· `if (true) { let y; }`（块级） |
| 使用场景 | 控制变量暴露范围，避免命名冲突                                                     |
| 注意事项 | `var` 只有函数作用域（无块级）；`let`/`const` 有块级作用域                         |

### 词法环境（Lexical Environment）

| 要素     | 内容                                                                                 |
| :------- | :----------------------------------------------------------------------------------- |
| 定义     | 引擎为作用域建立的运行时结构 = **环境记录**（变量登记表）+ **外部环境引用**（outer） |
| 语法示例 | 每个函数/块执行时自动创建，无需手写                                                  |
| 使用场景 | 理解作用域链与闭包的底层机制                                                         |
| 注意事项 | outer 引用把环境串成链，全局环境的 outer 是 `null`                                   |

### 作用域链（Scope Chain）

| 要素     | 内容                                                                      |
| :------- | :------------------------------------------------------------------------ |
| 定义     | 环境 → outer → outer…… 组成的查找链条；由**定义位置**决定                 |
| 语法示例 | `console.log(g, a, b)` 依次在 内层 → 外层 → 全局 查找                     |
| 使用场景 | 预测"这个变量在哪一层能访问到"                                            |
| 注意事项 | 规则：先找自己这层，找不到逐层向外，直到全局，再找不到报 `ReferenceError` |

### 提升（Hoisting）

| 要素     | 内容                                                                            |
| :------- | :------------------------------------------------------------------------------ |
| 定义     | 声明被"搬运"到作用域顶部；三种声明行为不同                                      |
| 语法示例 | `var v` → 提升为 `undefined` · `function f(){}` → 整体就绪 · `let l` → 进入 TDZ |
| 使用场景 | 理解"为什么可以先调用函数声明"                                                  |
| 注意事项 | 推荐先定义再使用，不依赖提升                                                    |

### 暂时性死区（TDZ）

| 要素     | 内容                                                            |
| :------- | :-------------------------------------------------------------- |
| 定义     | `let`/`const` 声明语句执行前，访问该变量直接报 `ReferenceError` |
| 语法示例 | `console.log(x); let x = 1;` → 报错                             |
| 使用场景 | 防"先使用后声明"的隐患                                          |
| 注意事项 | 越早报错越好修——这正是 let/const 比 var 安全的原因              |
