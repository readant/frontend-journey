# JavaScript 手册

## 概述

JavaScript 是浏览器的「大脑」：负责数据的存储与计算、页面的动态操作与用户交互。本手册按语言核心主题系统整理，从变量类型到异步与 DOM，是「忘了怎么写就来查」的完整储备。
