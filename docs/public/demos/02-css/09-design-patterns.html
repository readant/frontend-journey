3 清除浮动演示

当元素设置 float 后会脱离文档流，导致父元素高度坍塌。演示 4 种清除浮动的方法：overflow、::after 伪元素、display: flow-root、经典 clearfix hack。

父元素高度坍塌 问题

float: left
float: right

这是一段文字内容。浮动元素脱离文档流后，父元素的高度无法被浮动元素撑开，导致高度坍塌为 0。

清除浮动方案

float: left
float: right
当前模式：不清除 | 父元素高度：坍塌

代码示例与说明 CSS

/* 方案 1: overflow */ .parent { overflow: hidden; } /* 方案 2: ::after 伪元素 */ .parent::after { content: ""; display: block; clear: both; } /* 方案 3: display flow-root */ .parent { display: flow-root; } /* 方案 4: 经典 clearfix hack */ .clearfix::before, .clearfix::after { content: ""; display: table; } .clearfix::after { clear: both; }
不清除 浮动元素脱离文档流，父元素高度坍塌为 0
overflow: hidden 触发 BFC，包含浮动子元素。简单但会裁剪溢出内容
::after 伪元素 最常用的方案，无需额外 DOM，兼容性好
display: flow-root 新标准属性，语义更清晰，但部分旧浏览器不支持
clearfix hack 最经典的方案，使用 ::before + ::after 双伪元素，兼容性最好
