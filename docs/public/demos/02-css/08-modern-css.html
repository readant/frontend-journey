📦 BEM 命名演示

BEM（Block-Element-Modifier）是一种命名约定，帮助你创建可维护、可扩展的 CSS。格式为 block__element--modifier。

❌ 传统命名（Before）

问题：命名不清晰、嵌套过深、容易冲突
.card { } .card .title { } .card .card-title { } .card.featured { } .card.dark .title { } .card .btn.primary { } .sidebar .card .title { } .header .card .title { }

问题：
• .card .title 在不同上下文中样式不同
• .card.featured 依赖修饰符但无明确关系
• .sidebar .card .title 选择器嵌套过深

✅ BEM 命名（After）

优势：结构清晰、无冲突、可预测
.card { } .card__title { } .card__title--large { } .card--featured { } .card--dark .card__title { } .card__btn--primary { } .sidebar .card__title { } .header .card__title { }

优点：
• .card__title 明确属于 card 组件
• .card--featured 修饰符清晰表达状态
• 选择器深度不超过 2 层

🎨 OOCSS / SMACSS 演示

OOCSS（面向对象 CSS）强调结构与皮肤分离；SMACSS（可扩展模块化架构 CSS）将样式分为五个层次。

OOCSS：结构类

结构类定义布局和骨架，不关心视觉样式。

/* 结构：定义布局 */ .media { display: flex; gap: 1rem; } .media__image { width: 60px; flex-shrink: 0; } .media__body { flex: 1; }

OOCSS：皮肤类

皮肤类只关心视觉效果，不改变结构。

/* 皮肤：定义外观 */ .media--highlight { background: rgba(245,158,11,.15); } .media--bordered { border: 1px solid #ccc; } .media--separated { background: #f8fafc; }

SMACSS 五层架构

/* 1. Base: 基础重置 */ body, h1, p { margin: 0; } /* 2. Layout: 页面布局 */ .header { position: fixed; } .sidebar { width: 280px; } /* 3. Module: 可复用模块 */ .btn { padding: 8px 16px; } .card { border-radius: 12px; } /* 4. State: 状态修饰 */ .is-active { color: blue; } .is-hidden { display: none; } /* 5. Theme: 主题覆盖 */ .theme-dark .btn { background: #333; }

🚀 现代 CSS 特性

探索新一代 CSS 特性：伪类选择器 :is()、:where()、:has()，容器查询 @container，CSS 嵌套，颜色混合 color-mix() 和 light-dark()。

:is() 选择器

:is() 简化复杂选择器，取参数中最高优先级。

/* 之前 */ .card button, .card a, .card span.cta { } /* 之后 */ .card :is(button, a, span.cta) { }

上面的彩色按钮使用 :is(.primary, .featured) 和 :is(.danger, .delete) 匹配。

:where() 选择器

:where() 与 :is() 类似，但优先级始终为 0。

/* :where() 优先级为 0 */ :where(h1, h2, h3) { color: blue; } /* 可被任何规则覆盖 */ h1 { color: red; }

:has() 选择器

:has() 父选择器，根据子元素状态选择父元素。

/* 当内部有选中的 checkbox 时 */ .card:has(input:checked) { border-color: blue; } /* 当包含 .featured 类时 */ .container:has(.featured) { padding: 20px; }
✨ 已检测到选中状态，这是通过 :has() 实现的！

@container 容器查询

根据容器大小而非视口大小应用样式，实现真正的组件级响应式。

.card-container { container-type: inline-size; } @container (min-width: 300px) { .card { font-size: 18px; background: blue; } }

CSS Nesting 原生嵌套

CSS 原生支持嵌套，无需预处理器即可编写结构化样式。

.card { background: white; padding: 16px; &:hover { border-color: blue; } .title { font-weight: bold; } .content { font-size: 14px; } }

color-mix() 颜色混合

color-mix() 混合两种颜色，支持多种色彩空间。

/* 混合两种颜色 */ background: color-mix(in srgb, red 50%, blue); color: color-mix(in oklab, var(--primary), white 30%);

light-dark() 智能适配

light-dark() 根据浅色/深色模式自动选择对应颜色值。

background: light-dark(white, #1e293b); color: light-dark(#1e293b, #f1f5f9);

/* :is() 和 :where() 简化选择器 */ .el :is(a, button) { } :where(h1, h2) { } /* :has() 父选择器 */ .parent:has(.child) { } /* 容器查询 */ .container { container-type: inline-size; } @container (min-width: 300px) { } /* 原生嵌套 */ .card { &:hover { } } /* 颜色函数 */ color: color-mix(in srgb, red 50%, blue); background: light-dark(white, #1e293b);
