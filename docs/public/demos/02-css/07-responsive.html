移动优先 Mobile First

默认写移动端样式，使用 min-width 逐级增强

/* 默认：移动端 */ .demo { font-size: 14px; padding: 12px; } @media (min-width: 768px) { .demo { font-size: 16px; padding: 20px; } } @media (min-width: 1024px) { .demo { font-size: 18px; padding: 30px; } }
桌面优先 Desktop First

默认写桌面端样式，使用 max-width 逐级缩减

/* 默认：桌面端 */ .demo { font-size: 18px; padding: 30px; } @media (max-width: 1023px) { .demo { font-size: 16px; padding: 20px; } } @media (max-width: 767px) { .demo { font-size: 14px; padding: 12px; } }

容器查询 @container 演示

容器查询 (Container Queries) 是 CSS 的新特性，它根据容器自身的宽度而非视口宽度来调整样式。 这使得组件真正具备了自包含的响应能力，可以在任意宽度的容器中自适应。

与 @media 对比
@media 查询 视口相关

无论组件放在哪里，只要视口宽度相同，样式就相同。组件缺乏独立性。

.card-list { display: grid; gap: 16px; grid-template-columns: 1fr; } /* 依赖视口宽度 */ @media (min-width: 768px) { .card-list { grid-template-columns: repeat(2, 1fr); } } @media (min-width: 1024px) { .card-list { grid-template-columns: repeat(3, 1fr); } }
@container 查询 容器相关

根据容器实际可用空间调整，组件可在任何环境中保持最佳布局。

/* 1. 声明容器 */ .card-list { container-type: inline-size; container-name: cards; display: grid; gap: 16px; } /* 2. 定义默认样式 */ .card { font-size: 14px; } /* 3. 基于容器宽度调整 */ @container cards (min-width: 400px) { .card-list { grid-template-columns: repeat(2, 1fr); } } @container cards (min-width: 800px) { .card-list { grid-template-columns: repeat(3, 1fr); } }
/* 容器查询核心语法 */ /* Step 1: 在父容器上声明 */ .container { container-type: inline-size; /* 或: size, inline-size, block-size */ container-name: my-container; } /* Step 2: 基于容器宽度写规则 */ @container my-container (min-width: 400px) { .child { font-size: 18px; } } /* 容器查询条件可以是： */ /* - 宽度: min-width, max-width, width */ /* - 高度: min-height, max-height, height */ /* - 内边距: padding, scroll */
