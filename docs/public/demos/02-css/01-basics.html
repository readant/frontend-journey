优先级规则

内联样式：style="" 权重最高（1000），但可被 !important 覆盖

比较顺序：先比 ID 数，再比类数，最后比元素数

同级规则：后写的覆盖先写的

通配符：* 权重为 0，不参与特异性计算

示例对比

body div (0-0-2) vs .card (0-1-0) → .card 胜出

#header p (1-0-1) vs .nav .item (0-2-0) → #header p 胜出

a:hover (0-1-1) vs .link (0-1-0) → a:hover 胜出

📏 单位转换器

探索 CSS 中各种长度单位的换算关系。实时预览不同单位对元素尺寸的影响。

转换器

单位换算值说明
px100像素（固定）
rem6.25根元素字体 (16px)
em6.25当前元素字体 (16px)
vw10.42视口宽度 1%
vh14.29视口高度 1%
%100父容器百分比

📐 换算基准：

· 1rem = 根元素 font-size = 16px（默认）

· 1em = 当前元素 font-size（继承后可能不同）

· 1vw = 视口宽度的 1/100

· 1vh = 视口高度的 1/100

· % 相对于父元素的对应属性

可视化预览

100px

🔍 观察：改变单位类型后，拖动滑块感受不同单位的缩放行为。浏览器窗口变化时，vw/vh 会随之改变。
