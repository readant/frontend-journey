选择器实验室

在输入框中输入 CSS 选择器（如 div、.item、#main、li:nth-child(odd)），右侧会实时高亮匹配的元素。 支持标签、类、ID、属性、伪类、组合选择器等全部 CSS 选择器语法。

⌨️选择器输入
匹配数 0 类型 —

快速预设

*（全部） h1 .card li#main .highlight div p ul > li h1 + p h1 ~ p li:nth-child(odd) li:nth-child(3) li:first-child li:not(:first-child) a[href] a[href^='https'] button, a
💡 提示：选择器会实时验证。输入无效选择器会显示红色边框和错误提示。支持逗号分隔的多选择器组合。

属性选择器测试

属性选择器基于 HTML 元素的属性进行匹配。支持 [attr]（存在性）、[attr=val]（精确）、[attr^=val]（开头）、[attr$=val]（结尾）、[attr*=val]（包含）五种匹配方式。

⚙️选择器控制

存在性选择 [attr]

精确匹配 [attr=val]

开头匹配 [attr^=val]

结尾匹配 [attr$=val]

包含匹配 [attr*=val]
