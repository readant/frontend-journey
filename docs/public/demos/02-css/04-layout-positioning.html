4 浮动与清除

演示 float 如何使元素脱离文档流环绕显示，以及父元素高度坍塌的问题和 clearfix 解决方案。

浮动环绕效果 float

float: left
float: right

这是一段文字内容，文字会环绕在浮动元素周围。浮动元素脱离了文档流， 但其他内容（如这段文字）会自然地围绕在浮动元素的旁边进行布局。 注意观察左侧蓝色方块和右侧粉色方块的位置，以及文字的环绕方式。

清除浮动方案

float: left
float: right
当前模式：不清除 | 父元素高度：坍塌

代码示例 CSS

.float-left { float: left; } .float-right { float: right; } /* 经典 Clearfix 解决方案 */ .clearfix::after { content: ""; display: block; clear: both; }

清除方式说明

不清除： 浮动元素脱离文档流，父元素高度坍塌为 0（因为唯一的内容不在文档流中）
overflow: hidden： 让父元素形成 BFC（块级格式化上下文），包含浮动子元素
clear: both： 在浮动元素后方添加一个空元素，清除其前面所有浮动
::after 伪元素（推荐）： 无需额外 DOM 元素，自动在父元素末尾添加清除浮动的内容
