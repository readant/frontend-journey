## 阶段三：JS 交互开发

结合 [JavaScript 学习模块](/03-js/) 为上述页面添加交互能力，推荐练习方向：

- **表单验证**：用约束验证 API + `setCustomValidity` 为简历/考试页做完整校验
- **事件委托列表**：动态渲染文章/题目列表，用事件委托处理点击
- **异步数据渲染**：`fetch` + 模板字符串渲染评论、评分等动态数据
- **组件化**：用 ES Module 拆分工具函数，用 `class` 封装可复用组件
