# 页面结构标准：学习层每页闭环规范

> 让"零基础 → 独立上手项目"的培养目标落到每个页面上的写作契约。首次在 `03-js/02-functions` 落地并作为全站样板，之后按章节差距审查逐章对齐。

## 培养目标的总体原则

1. **先跑通，再深挖**：每个知识点先给"能跑的最小例子 + 生活类比"，原理与坑点放在"深入理解"阶段
2. **新知识永远建立在已学内容上**：页面间、章节间显式标注前置依赖，不跳步
3. **每页必须闭环**：概念引入 → 符号解释 → 标准语法 → 深入理解 → 评估测验 → 阶梯练习

## 每页的固定结构

```markdown
# 章节标题

::: tip 一句话记住
（本页核心的一句话概括）
:::

::: tip 前置要求
需要先掌握：xxx（链接到上一页）
:::

## 掌握目标
学完这一页，你能：...

## （正文：概念引入 → 符号课堂 → 深入理解）

## 评估小测验
3-5 题附答案解析（前置知识页必配）
```

- 每页开头声明"需要先掌握"（前置依赖）
- 页面间用 `::: tip 已掌握？` 提示承接上页内容
- 抽象概念至少 2 个不同角度类比 + 内存模型图（变量/引用/作用域可视化）

## 符号课堂模板

每个新语法符号（`function`、`()`、`=>`、`return` 等）**首次出现**时独立成节：

```markdown
### 符号课堂：`xxx`

- **干什么用**：一句话
- **写法**：代码
- 基础用法：…
- 常见错误（为什么错）：…
- 正确写法对比：…
```

要求：每个符号至少 3 个示例（基础 / 常见错误 / 正确写法对比），错误示例必须解释原因。

## 阶梯练习（每章结尾独立一页）

| 层级 | 题量 | 目标 | 难度 |
| :--- | :--- | :--- | :--- |
| 基础语法 | 10 题 | 只练一个语法点，会写 | ★☆☆ |
| 功能实现 | 8 题 | 组合 2-3 个知识点，会用 | ★★☆ |
| 综合应用 | 5 题 | 跨知识点真实小功能，会拆解 | ★★☆ |
| 项目实战 | 3 题 | 可运行小项目，能独立交付 | ★★★ |

每题包含：题目 → 思路引导（1-3 条提示，不直接给答案）→ 参考实现 → 易错点。

## 参考层速查四要素（标准 7）

参考层手册每个术语必须包含四要素：**定义 / 语法示例 / 使用场景 / 注意事项**。学习层不复制速查内容，通过 `::: tip 速查卡片` 链接。

## 全站一致性契约

新术语入库时同步检查四处（详见[改动影响面](./change-impact.md)）：
1. 场景索引 `2-scenarios/`
2. 星盘数据 `star-map-data.ts` + `graph-data.json`
3. 思维导图 `mindmap-data.yml`
4. 学习层页面内的速查卡片链接
