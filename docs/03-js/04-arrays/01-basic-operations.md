# 数组增删改查：方法与底层本质

## 它是什么

数组是**有序元素的集合**，可以想象成一排编号从 0 开始的格子，每个格子里放一个值。对数组的日常操作无非四件事：**增**（加元素）、**删**（删元素）、**改**（改元素）、**查**（找元素），对应一组自带的内置方法。

```javascript
const fruits = ["苹果", "香蕉", "橙子"];
fruits[0];              // 查："苹果"
fruits[1] = "西瓜";     // 改：把索引 1 换成 "西瓜"
```

关键要先理解数组的**本质**，才能理解后面所有方法的"脾气"。

## 数组的本质：一个特殊对象

数组在底层其实是一个**对象**，只是它"长得很像列表"：

- 键是**数字索引**（`"0"`、`"1"`、`"2"`……）
- 自带一个 **`length` 属性**，自动跟随元素个数变化
- 但它继承的是 `Array.prototype`，所以能用 `push`、`map` 等方法

```javascript
const arr = ["a", "b", "c"];
console.log(typeof arr);   // "object"（数组确实是对象！）

// 用对象的方式访问也完全成立
console.log(arr["0"]);     // "a"
console.log(arr[0]);       // "a"（更常规的写法）

// length 不是"数出来的"，而是最大索引 + 1
arr[9] = "x";
console.log(arr.length);   // 10（中间的空位仍然是"洞"，见 04.3 节）
```

::: tip 一句话理解
数组 = 数字键对象 + `length` + 数组方法。想通这一点，稀疏数组、类数组都顺理成章。
:::

## 会改变原数组的方法

这组方法**直接修改原数组**，操作完原数组就变了。要用"操作后的数组"，直接看原数组即可，**注意它们不会返回新数组**（`splice` 特殊，返回被删元素）。

### 1. 首尾增删：push / pop / unshift / shift

```javascript
const arr = [2, 3];

arr.push(4);       // 末尾追加 → [2, 3, 4]，返回新长度 3
arr.unshift(1);    // 头部插入 → [1, 2, 3, 4]，返回新长度 4
arr.pop();         // 删除末尾 → [1, 2, 3]，返回被删元素 4
arr.shift();       // 删除头部 → [2, 3]，返回被删元素 1
```

| 方法 | 作用 | 返回 |
| --- | --- | --- |
| `push(x)` | 末尾加 | 新长度 |
| `pop()` | 末尾删 | 被删元素 |
| `unshift(x)` | 头部加 | 新长度 |
| `shift()` | 头部删 | 被删元素 |

::: warning push / unshift 会逐个移动元素
`shift` / `unshift` 需要把后面所有元素**整体前移/后移**，数组很长时比 `push` / `pop` 慢。队列场景（先进先出）用它们没问题，高频操作请考虑用 `push` + 索引代替。
:::

### 2. 任意位置增删改：splice

`splice(开始索引, 删除个数, ...插入元素)` 是"瑞士军刀"——删、插、替换一把搞定：

```javascript
const arr = ["a", "b", "c", "d"];

arr.splice(1, 1);            // 从索引 1 删 1 个 → ["a", "c", "d"]
arr.splice(1, 0, "B");       // 在索引 1 插入（删 0 个）→ ["a", "B", "c", "d"]
arr.splice(1, 1, "X");       // 替换：删 1 个再插 1 个 → ["a", "X", "c", "d"]

// 返回被删掉的元素（数组形式），注意和 pop/shift 的区别
const removed = arr.splice(2, 1);   // removed = ["c"]
```

::: tip splice 的负数索引
`splice(-1, 1)` 从**倒数第 1 个**开始操作，`splice(1, 0, ...)` 的"删 0 个"是标准的插入手法。
:::

### 3. 排序与反转：sort / reverse

```javascript
const arr = ["b", "a", "c"];
arr.sort();          // 默认排序 → ["a", "b", "c"]
arr.reverse();       // 反转 → ["c", "b", "a"]
```

## 常见坑点：sort 的数字排序

`sort` 默认把元素**转成字符串**再按字符顺序排，数字会出大问题：

```javascript
[10, 9, 100].sort();                // [10, 100, 9]  ← 按字符串排的！
// "10" < "100" < "9"（字符顺序）

[10, 9, 100].sort((a, b) => a - b); // [9, 10, 100]  ✅ 必须传比较函数
```

::: danger sort 默认按字符串排序
**任何数字数组排序都必须传比较函数 `(a, b) => a - b`**（升序）或 `(b, a) => a - b`（降序）。不传比较函数的 `sort` 是新手最容易踩的坑，结果"看起来对又完全不对"。
:::

```javascript
// 升序 / 降序 模板
const nums = [3, 1, 10, 2];
nums.sort((a, b) => a - b);   // [1, 2, 3, 10]
nums.sort((a, b) => b - a);   // [10, 3, 2, 1]
```

## 不改变原数组的查找与判断

这组方法**不会动原数组**，只负责"看"，返回查找结果或布尔值：

```javascript
const arr = [1, 2, 3];

arr.indexOf(2);              // 1（找到返回索引，找不到返回 -1）
arr.includes(2);             // true（只需判断"有没有"时用它）
arr.find(x => x > 1);        // 2（返回第一个满足条件的**元素**）
arr.findIndex(x => x > 1);   // 1（返回第一个满足条件的**索引**）
arr.some(x => x > 2);        // true（有一个满足即可）
arr.every(x => x > 0);       // true（全部满足才 true）
```

| 方法 | 何时用 |
| --- | --- |
| `includes(v)` | 只要"有没有"，最简洁 |
| `indexOf(v)` | 需要知道位置（-1 表示没有） |
| `find(条件)` | 找**元素本身**（对象数组常用） |
| `findIndex(条件)` | 找**索引** |
| `some(条件)` | "存在一个"判断 |
| `every(条件)` | "全部满足"判断 |

::: warning indexOf 用严格相等
`indexOf` / `includes` 使用 `===` 比较，**找不到 `NaN`**（因为 `NaN !== NaN`）。要判断是否包含 `NaN`，请用 `includes`（它内部是 `SameValueZero` 语义，能匹配 `NaN`）。
:::

## 常见坑点

- `push` / `pop` / `sort` 等**改原数组**的方法，与 `map` / `filter` 等**返回新数组**的方法混用时，容易误以为"原数组没变"——先确认你调用的方法属于哪一类
- `sort` 不改比较函数就去排数字 → 结果按字符串排（见上文 danger）
- `splice` 的返回值是**被删元素数组**，不是修改后的数组；要"修改后结果"直接读原数组
- `find` 找不到时返回 `undefined`，用之前建议判空，避免 `undefined.id` 报错
- `every` 对空数组返回 `true`（"没有不满足的"），别拿它当"非空检查"

## 小结

- 数组本质是**数字键对象 + length + 方法**，索引从 0 开始
- 改原数组：`push` / `pop` / `unshift` / `shift` / `splice` / `sort` / `reverse`
- 不改原数组：`includes` / `indexOf` / `find` / `findIndex` / `some` / `every`
- 数字排序**永远**传比较函数 `(a, b) => a - b`
