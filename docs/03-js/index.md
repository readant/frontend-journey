# JavaScript 学习模块

系统化的 JavaScript 学习笔记：从变量类型到异步编程，八章递进构建完整知识体系，对标 CSS 的章节深度。**每章已细分为 3~5 个知识点子页面**，颗粒度更细、更适合循序渐进，每章配独立速查卡片。

## 学习顺序

| 顺序 | 模块 | 内容 |
| :----: | ------ | ------ |
| 1 | [变量与基础](/03-js/01-foundation/) | let/const、数据类型、类型转换、动态类型坑点 |
| 2 | [函数与闭包](/03-js/02-functions/) | 函数声明/表达式、箭头函数、作用域、闭包 |
| 3 | [对象与原型](/03-js/03-objects/) | 对象创建、原型链、class 语法、深浅拷贝 |
| 4 | [数组与方法](/03-js/04-arrays/) | map/filter/reduce、类数组、迭代器 |
| 5 | [异步编程](/03-js/05-async/) | 回调 → Promise → async/await、事件循环 |
| 6 | [DOM 操作与事件](/03-js/06-dom-api/) | 查询增删改、事件流、事件委托 |
| 7 | [ES 模块](/03-js/07-es-modules/) | export/import、动态导入、模块机制 |
| 8 | [错误处理与调试](/03-js/08-error-debug/) | try/catch、Promise 错误、Console/Source 调试 |

> 每章统一采用「引导总览 + 知识点子页」结构：章节首页给出学习路线，子页按「它是什么 → 核心机制 → 标准语法 → 深入理解 → 常见坑点 → 小结」组织，并配套独立速查卡片（`cheatsheet/data/` 与 `cheatsheet/dom/`）。

## 学完你将能

- 理解动态类型与强制转换，避开 JS 常见"诡异行为"的坑
- 掌握闭包与作用域链，理解 this 绑定规则
- 吃透原型链与 class 语法，熟练深浅拷贝
- 用 map/filter/reduce 写出声明式数组操作
- 理解事件循环与微/宏任务，熟练 async/await 异步编程
- 掌握 DOM 操作与事件委托，写出高性能交互
- 用 ES Module 组织模块化代码
- 建立错误兜底与调试方法论

## 学习建议

- **先 1-4 章**：打牢语言核心（变量、函数、对象、数组）
- **再 5-6 章**：进入浏览器世界（异步 + DOM，前端两大支柱）
- **最后 7-8 章**：工程化与防错（模块化 + 调试）
- **每章按子页顺序学**：章节首页有「本章路线」表，子页之间有明确的先后依赖（如先"变量声明"再"类型转换"）
- 每章末的「关联速查」卡片用于开发时快速查阅，与章节形成闭环
