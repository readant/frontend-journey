# 函数定义与调用：把动作打包成"自动售货机"

## 掌握目标

学完本页，你将能：

- 用售货机模型向别人解释"什么是函数"
- 看懂 `function`、`()`、`{}`、`;` 四个符号各自的作用
- 用函数声明写出第一个函数，并调用它

::: tip 前置要求
需要先掌握上一章的**变量与数据类型**（`let` / `const`、字符串、数字）。如果对 `let x = 1` 还不熟，请先回去复习。
:::

## 概念引入：函数就像一台自动售货机

想象你站在一台自动售货机前：

- 你**投币 + 按按钮**（这就是**输入**）
- 机器内部有固定的**计算过程**（按了"可乐"就出货口对准可乐）
- 你**拿到饮料**（这就是**输出**）
- 无论多少人用、用多少次，机器不用重新造——**一台机器，无限次复用**

JavaScript 里的<strong>函数（function）</strong>就是这个道理：

```javascript
function buyDrink(code) {        // 投币入口：code 是"你按的按钮"
  return "给你一杯" + code;       // 出货口：把结果交给你
}

buyDrink("可乐");   // "给你一杯可乐" —— 投币 → 出货
buyDrink("雪碧");   // "给你一杯雪碧" —— 换个按钮，机器不用重造
```

对照一下，售货机的每个部件都能在代码里找到影子：

| 售货机 | 函数 |
| :----- | :--- |
| 投币口 / 按钮 | `(code)` —— 括号里的**参数**（输入） |
| 机器内部程序 | `{ return ... }` —— 花括号里的**函数体**（计算） |
| 出货口 | `return` —— **返回值**（输出） |
| 一台机器无限复用 | 定义一个函数，调用 N 次 |

::: tip 一句话理解
**函数 = 把一段"输入 → 计算 → 输出"的流程打包，起个名字，随时可以重复使用。**
:::

## 符号课堂：`function` / `()` / `{}` / `;`

函数语法里藏着 4 个符号，新手最常被它们吓到。其实它们各管一件事，逐个来看。

### 符号一：`function` —— "我要定义函数了"

`function` 是**定义函数的关键字**，它告诉 JS 引擎："接下来的内容是一台自动售货机，请造好它。"

**示例 ① 基础用法**：关键字后跟函数名，表示"定义一个名为 sayHi 的函数"：

```javascript
function sayHi() {        // 定义
  console.log("你好");
}
sayHi();                  // 调用：你好
```

**示例 ② 常见错误**：忘记写 `function`，直接写 `sayHi() {}`：

```javascript
sayHi() {}                // ❌ SyntaxError：JS 不知道这是什么
// 正确写法：必须以 function 开头（或后面的表达式/箭头写法）
function sayHi() {}
```

**示例 ③ 大小写错误**：JS 是大小写敏感的，`function` 写成 `Function` 或 `Function()` 含义完全不同：

```javascript
function hi() {}          // ✅ 定义函数：function 小写
// Function() 是"创建函数的函数"，new Function() 极少用，别混淆
```

### 符号二：`()` —— "输入口 + 调用按钮"

圆括号 `()` 有两层含义，记住**看它在哪**：

1. **写在函数名后面**：函数体的输入口，里面放**参数**（下文参数页细讲）
2. **写在函数名后面（调用时）**：按下"调用按钮"，让机器立刻运转

**示例 ① 基础用法**：括号里放输入，括号跟着函数名执行：

```javascript
function add(a, b) {      // (a, b) 是输入口：声明两个"接收口"
  return a + b;
}
add(1, 2);                // (1, 2) 是调用按钮：填入 1 和 2，运转！
```

**示例 ② 常见错误**：**定义时忘了括号**，JS 会认为你在声明一个普通变量：

```javascript
function add a b { }      // ❌ SyntaxError：括号是函数定义不可缺少的一部分
function add(a, b) {}     // ✅ 正确
```

**示例 ③ 调用时忘记括号**：只写函数名，不写 `()`，你拿到的是"函数本身"而不是结果：

```javascript
function sayHi() { return "你好"; }
sayHi();                  // ✅ "你好" —— 带括号 = 执行
sayHi;                    // ⚠️ 返回函数本身（不会执行），常出现在"忘了调用"的 bug 里
// console.log(sayHi) 会打印整个函数源码 —— 这是调试时判断"有没有调用"的小技巧
```

### 符号三：`{}` —— "机器内部车间"

花括号 `{}` 包起来的部分叫**函数体（body）**，里面是这台机器实际执行的步骤。**括号只圈范围，不圈内容顺序**——里面的语句从上到下依次执行。

**示例 ① 基础用法**：函数体里可以放多行步骤：

```javascript
function greet(name) {
  const message = "你好，" + name;   // 第 1 步：组装消息
  console.log(message);              // 第 2 步：打印消息
}
greet("小明");
```

**示例 ② 常见错误**：**只写了左花括号 `{`，忘了右花括号 `}`**：

```javascript
function greet(name) {
  console.log("你好");        // ❌ SyntaxError：函数体没有闭合
// }                          // 忘写这一行
// 编辑器通常会标红；写代码时先写 {} 再填内容，能避免这类错误
```

**示例 ③ 一对空花括号**：允许，但函数"什么都不做"：

```javascript
function doNothing() {}       // ✅ 合法：空函数体
doNothing();                  // 执行了，但没有任何效果
```

### 符号四：`;` —— "这句话到此为止"

分号 `;` 表示**一条语句的结束**。函数表达式（把函数赋给变量）本质是"赋值语句"，所以末尾要加分号；函数声明则**不需要**。

**示例 ① 基础用法**：赋值语句末尾加分号：

```javascript
const fn = function () {       // 函数表达式：函数作为值赋给变量
  console.log("hi");
};                             // ✅ 表达式末尾加分号（习惯）
```

**示例 ② 常见错误**：声明后面加不加分号都行，但**混用**会让人困惑：

```javascript
function foo() {};             // ⚠️ 能跑，但函数声明不要求分号（多余）
const bar = function () {}     // ⚠️ 表达式忘加分号（虽然 ASI 会自动补，但不推荐依赖）
const bar = function () {};    // ✅ 表达式 + 分号，风格统一
```

**示例 ③ 危险场景**：一行开头是 `(` 或 `[` 时，前一行忘加分号会"串行"：

```javascript
const a = 1
(function () { console.log("hi"); })()   // ❌ 被解析成 1(function(){...})() 而报错
// 习惯：所有表达式语句末尾都加分号，避免 ASI 猜错
const a = 1;
(function () { console.log("hi"); })();
```

## 标准语法：三种定义方式

除了 `function` 声明，JS 还有两种常见的定义方式。本页先认识它们，箭头函数在 [04 页](/03-js/02-functions/04-arrow-functions) 详细讲：

### 方式一：函数声明（Function Declaration）

```javascript
function add(a, b) {
  return a + b;
}
add(1, 2);   // 3
```

### 方式二：函数表达式（Function Expression）

把函数当作值赋给变量，函数本身可以匿名：

```javascript
const sub = function (a, b) {
  return a - b;
};
sub(5, 2);   // 3
```

## 深入理解：函数声明 vs 函数表达式（提升差异）

两者的本质区别是**提升（hoisting）行为**不同：函数声明会整体提升（连函数体一起准备好），函数表达式只提升变量名（赋值之前值是 `undefined`）：

```javascript
// ✅ 函数声明：可以先调用后定义
hello();                    // "hi"
function hello() { return "hi"; }

// ❌ 函数表达式：调用时变量还没赋值
greet();                    // TypeError: greet is not a function
const greet = function () { return "hi"; };
```

::: warning 建议
依赖"提前调用"会降低代码可读性。**推荐做法是永远先定义、再使用**——不依赖提升，逻辑顺序一目了然。
:::

## 常见坑点

- 函数表达式忘记加 `const` / `let` 会创建**全局变量**，严格模式下直接报错
- IIFE（立即执行函数）前面**忘了分号**可能被上一行"吃掉"，见上面符号四示例 ③
- 一个文件里混用函数声明和箭头函数两种风格，维护成本高——和团队统一即可

## 小结

- 函数 = 自动售货机：参数（输入）→ 函数体（计算）→ 返回值（输出）
- `function` 声明函数；`()` 是输入口与调用按钮；`{}` 是函数体；`;` 结束表达式语句
- 三种定义方式：函数声明（有提升）、函数表达式（无提升）、箭头函数（下一页）
- 推荐**先定义再使用**，不依赖提升

## 评估小测验（自测后再对答案）

1. `function` 关键字的作用是什么？
2. `buyDrink("可乐")` 里的 `()` 起什么作用？
3. 下面的代码会输出什么？为什么？

```javascript
function a() { return 1; }
console.log(a);      // ？
console.log(a());    // ？
```

::: details 点击查看答案
1. 告诉 JS"我要定义一个函数"。
2. 调用按钮——执行函数；括号里的 `"可乐"` 是输入参数。
3. `a` 打印函数源码（拿到函数本身）；`a()` 打印 `1`（拿到执行结果）。**括号决定"拿机器"还是"拿饮料"**。
:::
