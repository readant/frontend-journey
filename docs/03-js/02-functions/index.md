# 函数与闭包

欢迎来到 JavaScript 的第二章！上一章我们学会了用变量和类型"存数据"；从这一章开始，我们要学会**把动作打包成函数**，并一步一步攻克 JS 里最容易被问倒的两个概念：`this`
和闭包。

本章按**七阶递进**组织，每一阶都建立在前一阶的基础上，请务必按顺序学习：

```
① 函数定义  →  ② 参数传递  →  ③ 返回值  →  ④ 箭头函数
      ↓
⑤ 作用域与词法环境（前置铺垫）
      ↓
⑥ 闭包  →  ⑦ this 绑定
      ↓
⑧ 阶梯练习（10+8+5+3）
```

## 学完你将能

- 用函数把重复代码"打包复用"，并说清函数声明与函数表达式的提升差异
- 正确处理参数（默认值、不定数量）与返回值，写出"输入 → 计算 → 输出"的清晰函数
- 判断什么时候该用箭头函数、什么时候必须用普通函数
- 用**内存图**画出作用域链，准确说出任意变量的查找路径
- 用闭包写出计数器、私有变量、防抖等经典模式，并避开内存泄漏
- 准确说出任意场景下 `this` 指向谁，并用 `call` / `apply` / `bind` 纠正
- 独立完成 3 个可运行的小项目练习（防抖搜索、计数器、任务管理器）

## 学习方法建议

- 每页代码都**亲手在浏览器控制台跑一遍**（F12 → Console），理解 > 记忆
- ①②③ 是语法基础，务必逐字看懂示例；④⑦ 是面试重点，⑤⑥ 是核心难点
- **闭包第一次看不懂很正常**：先跑例子、看结果，再对照内存图读原理，两遍就通了
- 每页结尾的「评估小测验」都要先自测再对答案，测不过就回看该页
