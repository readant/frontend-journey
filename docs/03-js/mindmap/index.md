# JavaScript 思维导图

> 以 **JavaScript 核心体系** 为中心的知识地图。四大分支由内向外辐射，每个节点对应站内详尽章节——学习时把握全貌，复习时定位盲区。

## 如何使用这张地图

- **纵览全局**：从中心节点出发，沿四大分支（语言核心 · 数据与结构 · 异步与浏览器 · 工程与防错）把握 JavaScript 知识脉络
- **逐个攻破**：点击任意节点直达对应章节，系统学习该主题的完整知识
- **查漏补缺**：对照地图回忆每个节点的关键点，卡壳的节点即是需要复习的盲区
- **自由探索**：拖拽画布平移视角，滚轮缩放调整粒度，点击分支可折叠已掌握的部分
