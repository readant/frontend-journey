# 初识 JavaScript：编程是什么，JavaScript 又是什么

## 掌握目标

学完本页，你将能：

- 用一句话向别人解释"什么是程序、什么是编程"
- 说出 JavaScript 的三种典型运行场景与"解释型语言"的含义
- 分清前端三剑客 HTML / CSS / JavaScript 各自的分工
- 眼熟 `const`、`=>`、模板字符串三个现代写法符号（不要求会用）

## 它是什么

在动手写第一行代码之前，先回答三个"劝退"级别的问题：**编程是什么？程序如何被计算机执行？JavaScript 在其中扮演什么角色？**
搞懂这三件事，后面学任何语法都不会"悬空"。

### 1. 编程是什么

**程序（Program）就是一组指令（Instruction）的有序集合**，告诉计算机"按什么顺序、做什么事情"。

```text
程序 = 指令 1 → 指令 2 → 指令 3 → ……
```

比如你要让计算机计算 `3 + 5`
并显示结果，至少需要两条指令：先算，再显示。人的大脑会"想当然"地完成，但计算机**不会推理，只会逐条执行指令**——这也是新手常困惑"我明明写了，为什么没反应"的根源：程序没按预期给出完整指令。

### 2. 计算机如何执行代码

计算机的 CPU 只认识一种语言——**机器指令**（一堆 0 和 1）。人不可能用它写程序，于是出现了**编程语言**，充当"人话 → 机器指令"的翻译层：

```text
源代码（人写的，如 let a = 1;）
   ↓  解析（parse）：把字符拆成语义单元
   ↓  执行：翻译成机器指令交给 CPU
结果
```

JavaScript 属于**解释型语言**：不需要像 C/Java 那样先整体编译成可执行文件，而是由引擎（浏览器里的 V8、Node.js）**边读边执行**。现代引擎会用 JIT（即时编译）把热代码编译成机器码提速，但对你来说，只需要记住一句：**写好代码，交给引擎，它立刻运行给你看。**

::: tip 一句话记住

**程序 = 一组按顺序执行的指令；编程 = 用人类能懂的语言写下这些指令，由引擎翻译成机器指令执行。**

:::

### 3. JavaScript 是什么

JavaScript 是**为浏览器而生的脚本语言**：1995 年诞生时，它只是为了给网页加一点"能动"的效果。如今它早已突破浏览器：

| 场景      | 用什么                  | 举例                               |
| --------- | ----------------------- | ---------------------------------- |
| 网页交互  | 浏览器内置引擎          | 点击按钮、表单校验、动画、请求数据 |
| 服务端    | Node.js                 | 写接口、爬虫、命令行工具           |
| 桌面应用  | Electron / Tauri        | VS Code、Obsidian                  |
| 移动/跨端 | React Native / uni-app  | 微信小程序、手机 App               |
| 游戏/图表 | Canvas / WebGL / 各种库 | 2D 游戏、数据可视化                |

**注意**：JavaScript 和 Java **毫无关系**（历史命名巧合），就像"汉堡"和"汉堡包"不代表同一个东西——不对，它们也没有关系。

## 三大分工：HTML / CSS / JavaScript

前端网页由"三剑客"协作完成，各管一段：

- **HTML**：结构——网页里有什么（标题、段落、按钮）
- **CSS**：样式——这些东西长什么样（颜色、大小、布局）
- **JavaScript**：行为——这些东西能干什么（点击、计算、请求、跳转）

```html
<button id="btn">点我</button>
<!-- HTML：有按钮 -->
<script>
  // JS：按钮被点击时弹出提示
  document.getElementById("btn").onclick = function () {
    alert("你点了我！");
  };
</script>
```

学习路线对应关系：`01-html` 学结构 → `02-css` 学样式 → `03-js` 学行为，本书的 03-js 模块正是补齐"行为"这一环。

## 标准语法与版本

JavaScript 的语法标准叫 **ECMAScript（简称 ES）**。你只需要知道两个里程碑：

- **ES5（2009）**：旧时代标准，兼容性极好但写法落后
- **ES6+（2015 年起的 ES2015 及之后各版本）**：现代 JavaScript，新增
  `let/const`、箭头函数、class、Promise、模块等。**现在写代码默认用 ES6+**

```javascript
// ES5 老写法
var name = "Alice";
function greet(name) {
  return "你好, " + name;
}

// ES6+ 现代写法（本项目统一采用）
const name = "Alice";
const greet = (name) => `你好, ${name}`;
```

::: tip 学习提示

本模块全部采用 **ES6+ 现代写法**。看到
`const`、箭头函数、模板字符串时不用慌，它们在后面的章节会逐个展开，现在只需要"眼熟"。

:::

## 符号课堂：`const` / `=>` / `` ` ``（先眼熟）

前面的代码里出现了 3 个"新面孔"符号。现在**只需要眼熟**——详细规则后面会逐个展开（`const` 在第 5 页"变量声明"、`=>`
在"箭头函数"章节）。

### 符号一：`const` —— "声明一个不许改的名字"

| 用法     | 示例                                                           |
| -------- | -------------------------------------------------------------- |
| 基础用法 | `const name = "Alice";` —— 声明常量 `name`，值固定为 `"Alice"` |
| 常见错误 | `const age = 18; age = 19;` —— 给 `const` 重新赋值会**报错**   |
| 正确写法 | `let age = 18; age = 19;` —— 需要改值的声明用 `let`            |

### 符号二：`=>` —— "箭头函数：把函数写短"

| 用法     | 示例                                                                |
| -------- | ------------------------------------------------------------------- |
| 基础用法 | `const greet = (name) => \`你好, ${name}\`;` —— 定义一个小函数      |
| 常见错误 | `const greet = name => 你好, name;` —— 少了模板字符串符号           |
| 正确写法 | `const greet = (name) => \`你好, ${name}\`;` —— 结果用 `` ` `` 包裹 |

## 常见坑点

- **别把 JavaScript 当 Java 学**：它们语法相似但完全是两门语言
- **别跳过"运行环境"**：写代码前先知道代码在哪运行（浏览器还是 Node），否则第一行代码就跑不起来
- **别追求"背语法"**：语言特性是工具，会用 > 会背；碰到不确定的，打开控制台试一下最快

## 小结

- **编程 = 写指令**，程序是"指令的有序集合"，计算机逐条执行
- **JS 是解释型语言**：源代码由引擎边读边执行，无需预先编译
- **前端三剑客**：HTML 结构 / CSS 样式 / JS 行为
- **JS 早已不止于浏览器**：Node.js 让它能写服务端、桌面、移动应用
- **现代写法 = ES6+**：本项目统一用 `const`、箭头函数等新语法

## 评估小测验（自测后再对答案）

1. **程序是什么？**
   - A. 一组按顺序执行的指令
   - B. 一堆随机的代码
   - C. 计算机的硬件
2. **JavaScript 是什么类型的语言？**
   - A. 编译型（先整体编译再执行）
   - B. 解释型（引擎边读边执行）
   - C. 汇编语言
3. **前端三剑客中，JavaScript 负责哪一块？**
   - A. 结构
   - B. 样式
   - C. 行为
4. **下面哪段是"现代写法（ES6+）"？**
   - A. `var name = "Alice";`
   - B. `const name = "Alice";`
   - C. 两者都是

::: details 点击查看答案

1. A —— 程序 = 指令的有序集合，计算机逐条执行
2. B —— JS 由引擎边读边执行，无需预先整体编译
3. C —— HTML 结构 / CSS 样式 / JS 行为
4. B —— `const` 是 ES6+ 现代写法，`var` 是 ES5 老写法

:::
