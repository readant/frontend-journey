# 变量与基础

欢迎进入 JavaScript 的第一章！这一章是**一切的地基**——不管是写函数、操作页面还是调接口，天天都要和变量、类型、转换打交道。把这章吃透，后面的路会顺畅很多。

JavaScript 是一门**动态类型**语言：变量本身不绑定类型，可以随时被赋值为任意类型。这和 Java、C 这类静态类型语言有本质区别，也是许多"诡异行为"的根源。

```javascript
let x = 42;          // 数字
x = "hello";         // 变成字符串 —— 合法！
x = { a: 1 };        // 变成对象 —— 依然合法
```

## 学完你将能

- 用 `const` 优先、`let` 兜底的正确姿势声明变量
- 分清原始类型与引用类型的本质差异（按值 vs 按引用）
- 看懂 JS 各种"诡异行为"（`"2" + 2`、`[] + []`）背后的转换规则
- 写出更安全的代码：永远用 `===`、用可选链和空值合并防崩溃
- 避开 `typeof null`、`NaN === NaN`、浮点精度等经典陷阱
